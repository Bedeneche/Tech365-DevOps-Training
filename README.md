# Employee API

A simple REST API built with **Node.js** and **Express.js** as part of my Tech365 DevOps training.

## Tech Stack

* Node.js
* Express.js
* Docker

## Features

* Get all employees
* Get an employee by ID
* Add an employee
* Delete an employee

## Run Locally

```bash
npm install
node index.js
```

API runs on:

```text
http://localhost:3000
```

## Docker

This project is also used to practice:

* Creating a Dockerfile
* Building Docker images
* Running Docker containers
* Port mapping
